# Nazdar careers pages

Upload everything in this folder to the root of your repository, keeping the folder structure.

Pages: index.html (overview), culture.html, community.html, benefits.html, history.html, leadership.html, faq.html.

CareersHeader.dc.html and CareersFooter.dc.html are the shared header and footer. Edit them once and every page updates. support.js and the _ds folder are required.

The pages load the header and footer at runtime, so they must be served over http(s) (GitHub Pages works). Opening the files directly from disk will not load them.

To publish: repository Settings > Pages > Deploy from branch > main / root.
